## What shipped

### 1. Marketing site (21 pages)
Generated by `build/landing/build.py` from `template.html` + page content files. Shared shell includes mega-menu nav, CTA band, Service Partners section, and redesigned footer on every page.

- Home — hero with **real PWA screenshot** (Owner dashboard), trust strip, 4-step onboarding, 3×3 roles grid (9 roles), 9 feature cards, legal strip (TPA/PRCA/ITA), testimonials
- Register — **5-step wizard**: Plan → Role → Account → Verify → Done
- Pricing (3 plans + comparison), Login, Features, How it works, Legal & Compliance
- Audience pages: Owners, Tenants, Partners, NRBs
- AI Caretaker, About, Blog + 3 full articles, FAQ (10), Contact, Terms, Privacy

### 2. Conversion funnel (real backend)
- `POST /api/register` → creates `subscribers` row (pending), emails **6-digit OTP**
- `POST /api/verify-otp` → activates account, sets `trial_end = +14 days`, sends welcome email
- `POST /api/resend-otp` → regenerates code (60s cooldown UI)
- E2E verified: register → OTP delivered to real mailbox → verify → `status=active`
- Duplicate-email → 409 with friendly message

### 3. i18n (EN ⇄ বাংলা)
- Nav toggle, instant client-side swap, `localStorage` persistence
- ~250 keys × 2 languages; Hind Siliguri font; `<html lang>` sync
- Full coverage: nav, footer, home, register, login, pricing, contact, FAQ, page heroes
- Blog bodies remain EN (heads translated) — noted gap

### 4. UX
- **Mega menu** (Tanvir-blog style): Platform / For you / Resources + direct Pricing & AI Caretaker; hover + keyboard (`focus-within`) on desktop; single-open accordion on mobile; group-aware active states
- **Dark mode** with audited text contrast (computed-color verified)
- Mobile sticky CTA, scroll-reveal, hover lifts, real screenshots, favicon, a11y labels
- Footer: socials, newsletter (real API), payment chips, "Made in Bangladesh 🇧🇩"

### 5. Trust & positioning
- Super Admin references fully removed from marketing site (public-facing)
- Trust strip (bKash/Nagad/SSLCommerz/DCCI/BIDA/e-Porcha), Service Partners section

## Architecture

```
Static (web/) ──build.py──► docs/landing/  (tunnel-served)
Flask (landing_api.py:8878)
  ├─ /           → docs/          (PWA prototype)
  ├─ /landing/*  → web/           (marketing site)
  └─ /api/*      → register, verify-otp, resend-otp, newsletter, contact, health
SQLite (landing.db): subscribers, contacts, newsletter_emails
SMTP (mail.inceptia.io:587): OTP + welcome + admin notifications
```

## Key decisions
- **DiziConCard-inspired** design language, KRTaker brand in REM-blue
- CSS design system: `web/css/style.css` (37KB, CSS variables — dark mode by variable flip)
- Register flow writes real subscribers (not localStorage) — foundation for Phase 2 auth
- Build mirror guarded against source corruption (safety abort)

## Known gaps (V2 targets)
- Blog bodies EN-only; SMS OTP (needs gateway); real domain + HTTPS (krtaker.com)
- No analytics, no sitemap/JSON-LD/OG yet
- Subscribers lack password hashing (register collects password but auth lands in V2 backend)
